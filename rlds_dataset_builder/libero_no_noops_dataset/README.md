# Libero No-Noops Dataset

This dataset builder converts enhanced Libero no-noops HDF5 datasets to RLDS format with comprehensive multimodal observations, real segmentation labels, and detailed motion descriptions.

## 🚀 Multi-Config Support

**NEW**: This dataset builder now supports multiple configurations for different LIBERO suites, allowing you to build and use separate datasets for each suite.

### Available Configurations

- **`libero_10`**: LIBERO-10 - 10 diverse manipulation tasks across different scenes
- **`libero_90`**: LIBERO-90 - 90 manipulation tasks with procedural generation  
- **`libero_spatial`**: LIBERO-Spatial - Tasks focusing on spatial reasoning and relationships
- **`libero_object`**: LIBERO-Object - Tasks focusing on object manipulation and interaction
- **`libero_goal`**: LIBERO-Goal - Tasks with complex goal specifications and constraints

### Requirements

- **Enhanced HDF5 files**: Generated by `regenerate_libero_dataset_enhanced.py`
- **Real motion descriptions**: Extracted from LIBERO environment using `describe_motion_from_action()`
- **Real segmentation labels**: Object instance names from `SegmentationRenderEnv`

## Usage

### 1. Set Environment Variable

Point to the **parent directory** containing all suite folders:

```bash
export LIBERO_DATA_DIR="/path/to/libero_no_noops_enhanced"
```

### 2. Build Specific Configs

Build individual LIBERO suites as separate datasets:

```bash
# Build LIBERO-10
tfds build libero_no_noops_dataset --config libero_10

# Build LIBERO-90  
tfds build libero_no_noops_dataset --config libero_90

# Build LIBERO-Spatial
tfds build libero_no_noops_dataset --config libero_spatial

# Build all configs
for config in libero_10 libero_90 libero_spatial libero_goal libero_object; do
    tfds build libero_no_noops_dataset --config $config
done
```

### 3. Load Specific Configs

Load datasets using config names:

```python
import tensorflow_datasets as tfds

# Method 1: Using tfds.load with config
ds_libero10 = tfds.load(
    'libero_no_noops_dataset',
    split='train',
    builder_kwargs={'config': 'libero_10'}
)

# Method 2: Using builder directly  
from libero_no_noops_dataset_dataset_builder import LiberoNoNoopsDataset

builder = LiberoNoNoopsDataset(config='libero_90')
ds_libero90 = builder.as_dataset(split='train')

# Method 3: List available configs
builder = LiberoNoNoopsDataset()
configs = [config.name for config in builder.BUILDER_CONFIGS]
print(f"Available configs: {configs}")
```

### 4. Access Suite Information

Each episode includes suite metadata:

```python
for episode in ds_libero10.take(1):
    suite = episode['episode_metadata']['suite'].numpy().decode()
    print(f"Suite: {suite}")  # Output: "libero_10"
    
    for step in episode['steps']:
        # Access enhanced motion descriptions and other data
        motions = step['language_motions'].numpy().decode()
        task = step['language_instruction'].numpy().decode()
```

## Dataset Structure

Each episode contains:

- **Observations**: 
  - `image`: Main camera RGB observation (224x224x3)
  - `wrist_image`: Wrist camera RGB observation (224x224x3) 
  - `depth`: Main camera depth observation (224x224x1)
  - `wrist_depth`: Wrist camera depth observation (224x224x1)
  - `seg`: Main camera segmentation observation (224x224x1)
  - `wrist_seg`: Wrist camera segmentation observation (224x224x1)
  - `state`: Robot end-effector state (8D: 6D pose + 2D gripper)
  - `joint_state`: Robot joint angles (7D)

- **Actions**: Robot end-effector actions (7D)

- **Language Instructions**: Task descriptions extracted from filenames

- **Language Motions**: 
  - `language_motions`: Previous motion descriptions separated by '|' (adaptive window 3-5 steps)
  - `language_motions_future`: Future motion descriptions separated by '|' (adaptive window 3-5 steps)

- **Episode Metadata**: 
  - `file_path`: Path to original HDF5 file
  - `demo_id`: Demo ID number within the episode
  - `seg_labels`: Real segmentation labels separated by '|'
  - `suite`: LIBERO suite name (e.g., "libero_10", "libero_90")

## Working with Multiple Suites

### Compare Different Suites

```python
import tensorflow_datasets as tfds

# Load different suites
suites = ['libero_10', 'libero_spatial', 'libero_goal']
datasets = {}

for suite in suites:
    datasets[suite] = tfds.load(
        'libero_no_noops_dataset',
        split='train',
        builder_kwargs={'config': suite}
    )

# Compare characteristics
for suite_name, ds in datasets.items():
    print(f"\n{suite_name.upper()}:")
    
    for episode in ds.take(5):
        steps = episode['steps']
        task = steps[0]['language_instruction'].numpy().decode()
        print(f"  Task: {task}")
        print(f"  Steps: {len(steps)}")
```

## Error Handling & Troubleshooting

### Common Errors

**❌ Missing Config**
```
ValueError: No config specified. Please use one of the available configs: ['libero_10', 'libero_90', ...]
```

**Solution**: Specify a config: `--config libero_10`

**❌ Data Directory Not Found**
```
FileNotFoundError: Data directory not found: /path/libero_10_no_noops/
Expected structure: /path/libero_10_no_noops/
```

**Solution**: Check your `LIBERO_DATA_DIR` points to parent directory containing `*_no_noops/` folders

**❌ Missing Enhanced Features**
```
AssertionError: MISSING ENHANCED FEATURES in task_demo.hdf5 - demo_0
Missing: ['motion_descriptions']
Suite: libero_10
```

**Solution**: Regenerate that specific suite:
```bash
python experiments/robot/libero/regenerate_libero_dataset_enhanced.py \
    --libero_task_suite libero_10 \
    --libero_raw_data_dir ./LIBERO/libero/datasets/libero_10 \
    --libero_target_dir /path/to/libero_no_noops_enhanced/libero_10_no_noops
```

## Features

- **🎯 Multi-Suite Support**: Build and use separate datasets for each LIBERO suite
- **🔥 Quality Enforcement**: Only accepts high-quality enhanced HDF5 files
- **📈 Complete Multimodal Observations**: RGB images, depth maps, segmentation masks for both cameras
- **🤖 Proprioceptive State**: Joint angles and end-effector pose with gripper state  
- **💬 Rich Motion Language**: Real motion descriptions for temporal reasoning and language-conditioned control
- **🏷️ Real Segmentation Labels**: Object instance names extracted from LIBERO environments
- **⚙️ Proper Data Processing**: Normalized depth values, single-channel segmentation masks
- **⏱️ Temporal Flags**: `is_first`, `is_last`, `is_terminal` for episode boundaries
- **🔄 Image Corrections**: 180-degree rotation to fix upside-down LIBERO images
- **🚨 Clear Error Messages**: Detailed guidance when requirements aren't met
- **📊 Suite Metadata**: Track which LIBERO suite each episode belongs to

## Benefits of Multi-Config Support

**Organized Development**: Work with specific LIBERO suites without loading all data
**Efficient Storage**: Build only the suites you need
**Clear Separation**: Each suite becomes a distinct dataset with its own characteristics
**Easy Comparison**: Load and compare different suites programmatically
**Scalable**: Add new LIBERO suites by adding new configs

Note: Images are rotated 180 degrees to correct for upside-down LIBERO orientation. Depth values are normalized to 0-255 range for consistent encoding.
